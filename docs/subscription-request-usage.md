# 订阅中的 CF 请求余额

完整 Clash / Mihomo 订阅会增加一个“CF 本账期剩余请求”信息组，刷新订阅时读取当前账户的真实套餐、账期及 Workers / Pages 请求统计。该统计为账户共享额度的估算值，可能延迟；付费套餐超出包含额度后按量计费。

信息组没有分流规则引用，不改变节点、DNS 或原有代理组。查询失败时显示“暂不可用”，不填入虚假余额；节点列表订阅及其他订阅格式保持原样。

Workers 不提供按 GB 扣减的流量包，因此不把请求次数写入按字节计量的 `subscription-userinfo` 响应头。Clash Verge 的订阅卡片只支持字节用量，请到“代理”页查看请求余额信息组。
