## 本地修改

AI 策略继续以 `sssstwee/xiaomao-ai-proxy/backend/edgetunnel-subscription/clash-base.yaml` 为唯一来源。变更见 [托管策略补丁](hosted-ai-routing.patch)，包含 YAML、Python 回归测试和 README 三个文件。

| 流量 | 策略与 DNS 目标 |
| --- | --- |
| Anthropic / Claude 核心服务 | 保留“Claude 专用”独立 fallback |
| OpenAI / ChatGPT / Codex 核心服务 | 保留“ChatGPT 专用”独立 fallback |
| 通用海外 AI | 从“默认代理”改为“故障转移” |
| Artifacts 公共资源 | 从“默认代理”改为“Claude 专用” |
| 普通流量 | 保留原负载均衡选项 |

Artifacts 使用的公共字体、脚本 CDN 也可能供其他应用使用；命中相同主机的流量会采用同一分流规则。fallback 在健康变化时仍可能换节点，同城并不等于固定同一个公网 IP。

Worker 新增显式 `/proxyip-only=IPv4:port?ed=2560` 路径：

- TCP 只拨指定回源，连接失败或重拨仍限制为同一地址。
- 不先拨业务目标、不展开 DNS/TXT 回源池、不进入默认反代兜底。
- 拒绝 UDP，包括 DNS/53；不再对测速站点本地合成 204。
- 非规范编码、冲突选择器、附加路径和额外查询参数失败关闭。
- 使用请求级目标，避免并发请求串用回源。
- 普通 `/proxyip=` 继续保留旧语义。

本地手工名单且 `random=false` 时，缺失、空白或仅有分隔符的 `ADD.txt` 返回 503，不会生成随机地区节点。

维护工具使用现有 Mihomo、Wrangler、GeoLite2 和内置转换器，没有新增 NPM 依赖。发布最低门槛为十个不同回源，默认目标十六个；只接受回源及 trace 实际公网出口均被本地城市库识别为 US / Los Angeles、且 API 检查通过的候选。不足十个时停止发布并保留原名单，不跨城市凑数。

探测凭据仅在内存物化，独立 Mihomo 配置通过 stdin 传入，不创建新的私人订阅文件。发布分支已实现私有 KV 内七天备份、并发改动检查、回读核对和失败恢复；这些写入分支尚未实际运行。完整用法见 [节点池维护说明](los-angeles-node-pool.md)。
